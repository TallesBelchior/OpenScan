# OpenScan
Repositório para  replicação do projeto open source da Open Scan.
O OpenScan é um conceito modular que pode ser usado para construir seu scanner 3D baseado em fotogrametria. Você pode simplesmente usar os módulos individuais e ajustá-los às suas necessidades (por exemplo, firmware, design para impressão 3D, PCB, processamento de fotogrametria na nuvem...). A peça central é um controlador de câmera/motor baseado em Raspberry Pi, que pode ser usado para controlar diversos equipamentos de fotogrametria.

O projeto se baseia na contribuição de muitas pessoas incríveis e de mente aberta, que criaram tutoriais no YouTube, comentaram no Reddit, publicaram no GitHub e em muitos outros lugares. Sem todos esses colaboradores voluntários, este projeto não seria possível.
